PPO-guided counterfactual chest radiography — evaluation-integrity branch

Five trained guidance arms, one evaluation protocol

Every arm below is a real PPO policy — 800 episodes per direction, trained from scratch — scored through the identical held-out pipeline (run_eval_cf.slurm → run_eval_reduce.slurm, 200 images per group). Nothing here is a no-policy countermeasure sweep or an offline proxy: where a comparison claims "confirmed," a paired significance test or a bootstrap confidence interval backs it, not a point-estimate eyeball.

Full metric table

CV is reported for completeness but is not a gate — it is scored against the same classifier that guided generation, so it is circular by construction. LHR and transfer ratio, scored against ground truth and independent held-out classifiers respectively, are the metrics that carry evidential weight.

Lesion Hit Rate lift

Fraction of edit mass landing inside the radiologist's box, divided by the chance baseline (box area fraction) — 1.0 is chance. Defined for p→n only: the n→p source images are classifier-negative and carry no lesion annotation.

Held-out transfer ratio, mean across validators
Δ(independent classifier) / Δ(guidance classifier). Dashed line at 0.15 marks arm_transfer.py's adversarial threshold. 3-model ensemble is scored on the reduced validator set {nih, pc} only — mimic_ch was dropped once mimic_nb joined guidance — so it is not directly comparable to the other four arms' 3-validator mean.
