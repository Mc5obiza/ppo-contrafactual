\section*{LLM Usage Statement}
\label{sec:llm-statement}

We used an LLM-based coding and writing assistant (Claude, Anthropic) in two ways. (i) Code: it helped write and debug parts of the experiment and analysis code, including evaluation, bootstrap and paired-test scripts and job-submission scripts, and it helped trace reported values back to the logs and result files they came from. (ii) Writing: it helped edit and restructure the manuscript text, tables and captions. The authors designed the study and the method, chose the experiments, ran all experiments, and checked every number and claim in the paper against the saved outputs. No LLM was used to generate data, images or annotations, and no LLM is part of the method.
