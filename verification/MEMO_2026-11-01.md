## 4. J12: grid coverage, the −2.00 vs −0.20 gap, local-grid proposal (part5/j12_coverage.py → .md/.json)
Timing: stage 1 (18511304) finished 2026-11-01 ≈00:30 and stage 2 (18511305) ran 00:31-01:54, before decision 4
arrived, so there was nothing left to cancel. The coarse grid used 7.7 GPU-h (pilot + stage 1 + stage 2; estimate was ~12).

Why the best configuration's return was far below the policy-mean reference: a design error in my grid, plus the pilot chunk.
1. The tau control. The env pays the stop bonus R_stop = valid × [tau > 0.5], weight LAM_STOP = 2.0, ×2.25 in n→p
   (factory/environment.py l.458). The coarse grid set every non-grid raw action to 0, so tau = sigmoid(0) = 0.5 exactly
   and never earned it. The reference (tau 0.92 n→p, 0.62 p→n) did. tau enters nothing else: it changes no image, and
   episodes end at the first valid step regardless of tau. So the missing bonus is exactly
   2.0 × scale × 0.99^(n_steps−1) per valid episode, and can be restored from the logged rows without a GPU.
2. The −2.00 was the pilot chunk only (all guidance bias 0.85, 2 passes). Over all 54 configs with the bonus restored:
   - n→p best +11.31 vs reference +11.26 (stage 1, 12 images); 7/54 grid points ≥ reference.
   - p→n best +3.28 vs reference −0.20; 11/54 grid points ≥ reference.
3. Restoring the bonus leaves the stage-1 top 6 unchanged in both directions (6/6), so stage 2 ran on the right configs.
   The selection step now uses the corrected return.
Selected on the coarse grid (48 training-fold images, corrected): n→p g0.25_1.15_0.85_2 (+11.218), p→n g0.25_1.15_1.27_3
(−2.622; stage-2 images are harder). Both sit on the grid's lowest strength (0.25), i.e. at a boundary of the grid.
